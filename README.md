# Plan Laser – GLM 50 C

Appli web (PWA) de dessin de plans reliée au télémètre laser Bosch GLM 50 C en Bluetooth (Web Bluetooth, Chrome Android).
Fonctionne hors ligne une fois installée. Les plans restent stockés dans l'appareil.

Mise à jour : modifier les fichiers puis changer `CACHE` dans `sw.js` (plan-laser-v2, v3…).
